# MuseVis — Frontend Demo

A standalone, responsive music discovery and visualizer presentation built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in any modern browser. No build step, package installation, server, environment variables, or backend is required.

## Included
- Sample music library with search
- Mood filters
- Simulated playback controls and progress
- Favourites
- Animated visualizer

## Demo-only behaviour
All tracks and playback states are sample data. Playback is simulated; no audio is streamed. There is no login, Spotify connection, Firebase, API, database, server, or credential requirement.

This repository intentionally contains only the frontend demo.
